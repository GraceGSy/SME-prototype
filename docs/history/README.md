# Historical run notes

These reports document earlier corpus preparation, experiments, and cost
estimates. They are evidence about those dated runs, not instructions for the
current pipeline. Most dated rescue, preflight, and curation helpers cited
inside them were retired; use Git history if an exact historical reproduction
is needed. Two legal provenance scripts remain at their recorded paths under
`helpers/`. Do not apply these reports' cost estimates or commands to a new run.

For a new corpus or graph, start with the [main README](../../README.md) and
the current [pipeline flow](../../PIPELINE_FLOW.md). The
[Sherlock assessment](../sherlock-experiment.md) explains the method's observed
semantic limitations.
