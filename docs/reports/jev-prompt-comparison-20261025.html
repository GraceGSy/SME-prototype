Time and cost

The 24 fresh calls used 304,411 input tokens, approximately $0.0128 (1.28 US cents) at TypeSafe's published $0.042 per million input tokens; output tokens are free. This is a token-based estimate, not an invoice. It excludes any unknown charge for the earlier rejected request. See the official model and pricing table.

Noul used 8.7% more input tokens than cleaned Choice and had similar observed latency. Cleaned Choice itself used 6.1% more tokens than the saved legacy requests. This probe therefore does not show a token-cost reduction. Total measured selector-call time was 6.72 seconds, including transport and local selection/cache work but excluding process startup and report processing.

No Claude calls occurred. These selector timings and costs do not describe a full pipeline run, where question and explanation generation still contribute cost and latency. One observation per case and fixed variant order are insufficient for a reliable speed benchmark.
