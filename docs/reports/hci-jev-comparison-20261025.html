What changed

The main difference is reduced coverage, not just reworded questions. Against the same-granularity baseline, 31 paragraphs change membership and another 75 change only their parent scope. Reporting all 106 as changed matches would overstate membership churn.

Source-question wording also changes: none of the 66 structural questions and only 1 of the 221 paragraph questions remain identical after normalization. Mean TF-IDF cosine is 43.4% for structural questions and 44.6% for paragraph questions. These scores measure lexical overlap, not whether the questions express the same meaning.

Review observations, not automatic quality labels

  • Likely missed match: funding acknowledgments. Both paragraphs credit NSF grant IIS-2107391 and Sloan fellowship FG-2023-19960, and both disclaim funder involvement. The older runs group them together; the new run leaves them separate even though their parent sections match. Jev selects the counterpart with probability 0.61 in the forward direction, then selects NO_MATCH with probability 0.53 versus 0.47 in reverse. The reciprocal rule rejects the pair. This is a substantive selection disagreement, not a probability-validation failure.
  • Likely missed match: highlighting helps people skim text. The older runs join participant feedback about color highlighting and efficient skimming. The new run separates the paragraphs and their corresponding structural units. That removes a plausible cross-system result correspondence. Different parent scopes also change which paragraph candidates the pipeline considers.
  • Useful additions relative to the same-granularity baseline: the new run matches introductory descriptions of each tool's new features, and matches the two contribution summaries. These pairs have a plausible common rhetorical role.
  • Some removals may help: the older same-granularity run groups AbstractExplorer's JSON precomputation/latency paragraph with CorpusStudio's sentence-embedding procedure. Those passages describe different implementation operations. Their removal could improve specificity, although that is a review judgment rather than a measured precision gain.
  • Some procedural matches remain stable: participant recruitment, remote-session logistics, warm-up activities, and closing surveys/interviews retain cross-paper paragraph matches.

What this does not establish

None of the historical runs isolates the effect of Jev. The same-granularity run used lower generative limits and effort; the latest old run used different source scopes and eventually added three papers. Historical configuration comes from run-level settings when per-revision snapshots are absent and may describe a later attempt. The new run also regenerated almost every source question.

Coverage does not measure recall without reference labels, and pair agreement does not measure precision. The reviewed misses are reasons to investigate, not a corpus-wide error estimate. Do not call the new run an accuracy improvement on the evidence available.

Deterministic comparison tool

The working mockup is a Python CLI that writes standalone HTML and JSON. It needs no server, credentials, generative model, embedding model, or new dependency. It never changes saved runs.

  • Coverage counts units with a cross-paper partner, overall and per paper.
  • Match similarity includes pair Jaccard, pair F1 agreement, baseline-pair retention, and peer-set overlap. Same-paper fan-in does not inflate cross-paper scores.
  • NetworkX maximum-weight matching aligns groups globally by shared-member count. Unaligned groups remain visible. Question wording does not affect alignment.
  • NetworkX graph intersection, symmetric difference, and identity-preserving isomorphism compare actual source matches. Exact edge edits use fixed source IDs instead of an unrestricted, potentially timeout-dependent graph-edit search.
  • Question scores include normalized exact agreement, token Jaccard, and lexical TF-IDF cosine. TF-IDF fits each question comparison locally; scores are not calibrated across different corpora and do not detect semantic equivalence or contradiction.
  • Expandable rows show source passages, old/new questions, membership changes, and parent-scope-only changes. Explicit projection warnings prevent different granularities from silently appearing comparable.
